# Job Search Email Tracker & Pipeline Manager

Универсальный инструмент для автоматического учета откликов, отказов, приглашений и офферов с нескольких почтовых ящиков Gmail.

Скрипт рассчитан на **регулярное использование по ходу поиска работы**.

---

## 🚀 Как запускать сейчас и в будущем

Учетные данные ваших ящиков уже сохранены в локальном файле `accounts.json`. Для обновления статистики достаточно просто запустить:

```bash
cd /Volumes/work/job_search_tracker
./tracker.py
```

### Запуск с параметрами (опционально)

- **Сканировать с определенной даты**:
  ```bash
  ./tracker.py --since 01-Sep-2026
  ```
  *(по умолчанию анализирует с `01-Aug-2026`, чтобы у вас всегда была полная картина поиска)*.

- **Указать свое имя файла для отчетов**:
  ```bash
  ./tracker.py --csv my_report.csv --html my_report.html
  ```

---

## 🧠 Что умеет скрипт

1. **Связывает отклики и ответы между ящиками**:
   - Если вы откликнулись с одного ящика, а ответ/отказ пришел на другой — они объединяются в одну строку компании.
   - Если подтверждение пришло от ATS-системы (Greenhouse, Lever, Ashby, Workday, SmartRecruiters, NoFluffJobs), а отказ написал рекрутер с личной корпоративной почты — они связываются в единую цепочку.

2. **Отслеживает стадии и сроки ожидания (Lifecycle)**:
   - 🟡 **На рассмотрении (In Review)** — отклик отправлен / подтвержден, ожидается ответ.
   - 🟢 **Приглашение (Interview / Assessment)** — онлайн-тестирование, скрининг, созвон с рекрутером.
   - 🔴 **Отказ (Rejected)** или **Отказ (после интервью)**.
   - 🟢 **Оффер (Offer)**.
   - ⏳ **Дней без ответа** — подсчитывает, сколько дней прошло с последнего обновления, чтобы вы знали, когда пора отправить follow-up или когда вакансию можно считать закрытой.

3. **Универсальная фильтрация шума**:
   - Исключает рассылки вакансий (LinkedIn Job Alerts, дайджесты, рекомендации).
   - Исключает уведомления безопасности (Google App Passwords, 2FA, OAuth).
   - Исключает служебные письма о создании аккаунтов на сервисах, доставку посылок и рекламу.
